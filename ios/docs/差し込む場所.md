# A-1 / A-2 / A-3 を差し込む場所

ファイルを3つ足して、既存の4か所に呼び出しを入れるだけ。

```
済み   GameJuice.swift        A-3（止め・揺れ・スロー・ふちの光）
済み   MilestoneFx.swift      A-1（数字ドン）
済み   MilestoneAudio.swift   A-2（節目の音）
済み   GameAudio.swift        節目用のバスと残響を足した
のこり GameSession.swift      下の 1〜4
のこり BoardCanvas.swift      下の 5〜7

ファイルは入っているが、**まだどこからも呼ばれていない**ので、
下の 1〜7 を入れるまで見た目と音は変わらない。
```

---

## GameSession.swift

### 1. 持ち物を足す

```swift
var juice = GameJuice()
var milestone = MilestoneFx()
```

### 2. 打つたびに段をリセット

`launch`（`engine.launch` を呼んでいるところ）の直後に：

```swift
milestone.reset()
```

**これを忘れると2回目以降に数字ドンが出なくなる。**段は「1回の放出ごと」に数える。

### 3. `tick(real:)` の物理を、止めを通してから進める

いまの

```swift
if busy {
    var left = real
    let step = Engine.physicsSubstep
    while left > 0 { ... engine.stepPhysics(dt: d) ... }
}
```

を、こう包む：

```swift
// 玉が4つより多いときはスローにしない（ごちゃつくため）
let advance = juice.tick(real: real, slowHint: shotBallsMax <= 4 && slowWanted)
if busy, advance > 0 {
    var left = advance
    let step = Engine.physicsSubstep
    while left > 0 {
        let d = min(step, left)
        engine.stepPhysics(dt: d)
        left -= d
        if !busy { break }
    }
    for b in engine.balls where b.state == .fly {
        b.trail.append((b.x, b.y))
        if b.trail.count > 8 { b.trail.removeFirst() }
    }
}

// 数字ドン（物理を進めたあと）
if running, let level = milestone.check(pot: engine.pot, shotScore: engine.shotScore, juice: &juice) {
    GameAudio.shared.playMilestone(level: level)
    potPulse = 1.5
    GameHaptics.pattern(min(5, 1 + level / 2), intervalMs: 70)
}
milestone.tick(real: real)
```

`slowWanted` は「×5 に入りそうな玉があるか」。最初は `false` 固定でよい。

### 4. `hooks.hit` に手応えを足す

いまは音と振動だけなので、**■と▲に止めと揺れを入れる**。ここが「当たった感じ」の正体。

```swift
switch kind {
case .square:
    self.juice.addHitStop(0.05)
    self.juice.addShake(0.2)
case .tri:
    let count = self.engine.balls.count
    self.juice.addHitStop(count >= 9 ? 0.1 : 0.06)
    self.juice.addShake(min(0.6, 0.2 + Double(count) * 0.02))
    if count >= 9 { self.juice.slowPulse = 0.35 }
default:
    break
}
// 10回ごとに軽く手応え
if n % 10 == 0 {
    self.juice.addHitStop(0.05)
    self.juice.addShake(0.15)
}
```

`hooks.perfect` にも：

```swift
self.juice.addHitStop(0.45)
self.juice.addShake(1.1)
self.juice.flashEdge(.cycle, width: 44)
```

受け皿に入ったとき（`onLand`）の ×5 にも：

```swift
self.juice.addHitStop(m >= 5 ? 0.14 : 0.05)
if m >= 5 {
    self.juice.addShake(0.45)
    self.juice.flashEdge(.solid(DD.red))
}
```

## BoardCanvas.swift

### 5. 台を揺らす

`draw(ctx:size:)` で台の座標へ移す直前に：

```swift
let shake = session.juice.shakeOffset
ctx.translateBy(x: ox + shake.width, y: shake.height)
```

### 6. 背景の大きな数字を、数字ドンの分だけ消す

「大きな数字を重ねない」というルール。`// ---- 今回のポイント（背景の大きな数字）----` のところで、
いまの不透明度に **`* (1 - session.milestone.visible)`** を掛ける。

### 7. 数字ドンとふちの光を描く

数字ドンは**いちばん最後**（釘・受け皿・玉より手前）。ふちの光は**台の変形の外側**。

```swift
// …釘・受け皿・玉を描いたあと、台の座標系のまま
let f = e.field()
session.milestone.draw(
    ctx: ctx,
    logicalWidth: Engine.logicalWidth,
    centerY: (f.top + f.bottom) / 2 - 10,
    font: { size in .custom("HelveticaNeue-Bold", size: size) }
)

// 変形を戻してから、画面のふち
session.juice.drawEdge(ctx: originalCtx, size: size)
```

`originalCtx` は `translateBy` や `scaleBy` を掛ける前の `ctx` を控えておいたもの。

## 入れ終わったら確かめること

1. **100点ごとに数字が飛び込むか。**出ないときは `milestone.reset()` の位置を疑う
2. **色。**100〜400は赤、600〜900は青、500と1000は赤・黄・青が高速で入れ替わる
3. **1000点まで出るか。**`min(10, value / 100)` なので1000で頭打ち
4. **■に当たった瞬間、一瞬止まるか**
5. **▲で玉が9個を超えたらスローになるか**
6. **節目の音が釘の音に埋もれないか。**埋もれるなら `duck` の 0.18 を下げる
7. **背景の大きな数字が、数字ドンの間だけ消えるか**
