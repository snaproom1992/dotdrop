# 演出（A-1 / A-2 / A-3）の入れ場所

**呼び出しまで入れてある。**pull して Run すれば、そのまま演出が出る。
ここは「どこに何が入っているか」の地図。あとから直すときに読む。

```
GameJuice.swift        A-3　止め・揺れ・スロー・ふちの光
MilestoneFx.swift      A-1　100点ごとの数字ドン
MilestoneAudio.swift   A-2　節目の音（ブラス・ベル・うねり・太鼓）
GameAudio.swift        節目用のバス（fan）と残響を足した
GameSession.swift      1〜4 を入れた
BoardCanvas.swift      5〜7 を入れた
```

---

## GameSession.swift

### 1. 持ち物

```swift
@ObservationIgnored var juice = GameJuice()
@ObservationIgnored var milestone = MilestoneFx()
```

### 2. 打つたびに段をリセット

`releasePull()` の中、`potShow = 0` の次に `milestone.reset()`。
**これを消すと2回目以降に数字ドンが出なくなる。**段は「1回の放出ごと」に数える。

### 3. 物理を、止めを通してから進める

`tick(real:)` の中。`juice.tick(real:)` が「進めてよい秒数」を返すので、それだけ進める。
止めている間は 0 が返るので、玉が止まる。物理を進めたあとに `milestone.check(...)` を見て、
段が上がっていたら音（`playMilestone`）と振動を鳴らす。

スローを足したくなったら `juice.tick(real:slowHint:)` の第2引数に
「×5 に入りそうな玉があるか」を渡す。いまは渡していない（▲で9個を超えたときだけスローになる）。

### 4. 手応え

- `hooks.hit` の `.square`：止め 0.05・揺れ 0.2
- `hooks.hit` の `.tri`：玉の数で強くなる。9個以上でスロー 0.35
- `hooks.hit`：10回ごとに軽く止めと揺れ
- `hooks.perfect`：止め 0.45・揺れ 1.1・ふちは赤黄青の入れ替え（いちばん大きい）
- `onLand`：×5 は止め 0.14・揺れ 0.45・ふちが赤く光る

## BoardCanvas.swift

### 5. 台を揺らす

`pt()` に `session.juice.shakeOffset` を足してある。**背景と帯は揺らさない**
（全面が揺れると読めない。台と釘と玉だけが揺れる）。
受け皿の中の文字・●・点線の丸も `pt()` を通すようにした。ここを直し忘れると受け皿だけ揺れない。

### 6. 背景の大きな数字を消す

`let bgNumAlpha = session.potAlpha * (1 - session.milestone.visible)`。
「大きな数字を重ねない」というルール。数字ドンが出ている間だけ背景の数字が消える。

### 7. 数字ドンとふちの光

`draw()` のいちばん最後。数字ドンは釘・受け皿・玉より手前。
ふちの光（`juice.drawEdge`）は台の揺れの外側なので、揺れても画面のふちに沿う。

## 確かめること

1. **100点ごとに数字が飛び込むか。**出ないときは `milestone.reset()` の位置を疑う
2. **色。**100〜400は赤、600〜900は青、500と1000は赤・黄・青が高速で入れ替わる
3. **1000点まで出るか。**`min(10, value / 100)` なので1000で頭打ち
4. **■に当たった瞬間、一瞬止まるか**
5. **▲で玉が9個を超えたらスローになるか**
6. **節目の音が釘の音に埋もれないか。**埋もれるなら `duck` の 0.18 を下げる
7. **背景の大きな数字が、数字ドンの間だけ消えるか**
8. **ふつうとフィーバー中の両方で見ること。**背景がマスタードになるので、赤と青の見え方が変わる
